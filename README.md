# Tempad to Map

Shows your Tempad teleport locations as JourneyMap waypoints.

Tempad locations are synced from the server to each player, so the mod works
in single-player, LAN, and dedicated-server worlds. Additions, edits, and
deletions in Tempad are reflected in JourneyMap.

## Requirements

- Minecraft 1.21.1 with NeoForge 21.1.x
- [Tempad](https://modrinth.com/mod/tempad) 3.x on both sides
- [JourneyMap](https://modrinth.com/mod/journeymap) on the client to display waypoints

JourneyMap is optional for loading the mod. Without it, Tempad locations are
still received but no waypoints are created.
